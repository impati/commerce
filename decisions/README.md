# 기술 결정 기록

무엇을 골랐고 왜 골랐는지, 그리고 어떤 조건에서 다시 볼지를 남긴다. 코드를 읽어도 알 수 없는 것이 여기 있다 — 채택하지 않은 대안과 그 이유다.

## 다른 문서와의 경계

| 위치 | 담는 것 |
| --- | --- |
| `decisions/` | 무엇을 왜 골랐나. 재검토 조건까지 |
| `problem/` | 겪은 문제와 기술 조사. 사용자가 요청할 때만 쓴다 |
| `docs/` | 설계 — 무엇을 만드는가 |
| `CLAUDE.md` | 작업 룰 — 어떻게 작업하는가 |
| `NEXT.md` | 이어서 할 일 — 우선순위·합의·미결정 |
| `git log` | 무엇을 왜 했나 |

결정을 뒤집을 때는 기존 문서를 고치지 않고 새 번호를 만들어 이전 결정을 대체(supersede)한다고 적는다. 고쳐버리면 왜 뒤집었는지가 사라진다.
