# local 프로파일 스모크

- **ID:** BL-0006
- **기록일:** 2026-08-16

## 배경

`./gradlew test`가 절대 실행하지 않는 구간이 있다 — `local` 프로파일 코드와 파일 DB다. 테스트는 매번 빈 in-memory DB에서 시작하므로 여기서 나는 문제를 구조적으로 잡을 수 없다.

이 구간에서 이미 두 번 놓쳤다.

| 놓친 것 | 왜 테스트가 못 잡았나 |
| --- | --- |
| 적용된 Flyway 마이그레이션 수정 → 체크섬 불일치로 기동 실패 | in-memory DB는 매번 처음부터 적용해 충돌이 생기지 않는다 |
| 데모 시드가 재시작마다 배송지를 하나씩 추가 | `@Profile("local")` 코드는 테스트에서 빈으로 만들어지지 않는다 |

## 목표

`local` 프로파일로 띄우고 두 번 재시작해 상태가 늘어나지 않는지 확인하는 스모크가 있다. 확인할 것은 셋이다 — 파일 DB에 마이그레이션이 적용되는가, 시드가 멱등한가, 재시작 후에도 기동하는가.

`make verify`에 넣으면 매번 느려지므로 별도 타깃(`make smoke`)으로 두고 커밋 훅에는 넣지 않는 쪽이 맞다고 본다.
