# 테스트 격리를 규율이 아닌 구조로 만든다

- **ID:** BL-0013
- **기록일:** 2026-08-16

## 배경

`@SpringBootTest` 컨텍스트와 in-memory DB가 테스트 간에 공유되므로, 각 테스트가 자기 데이터를 직접 만들고 고정 id를 피해야 한다. 지금은 이것이 작성자의 규율에만 의존한다. 어기면 PK 충돌이나 순서 의존 실패로 나타나고, 원인을 찾기 어렵다.

## 목표

테스트가 서로의 데이터를 보지 않는 것이 구조로 보장된다. `@Transactional` 롤백으로 바꿀지, 다른 방법을 쓸지 정한다.
