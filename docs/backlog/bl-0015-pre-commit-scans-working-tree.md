# pre-commit 훅이 working tree를 검사한다

- **ID:** BL-0015
- **기록일:** 2026-08-16

## 배경

[pre-commit 훅](../../scripts/git-hooks/pre-commit)이 스테이징된 내용이 아니라 working tree를 검사한다. 부분 커밋을 하면 커밋되지 않는 변경까지 포함해 검증하므로, 통과한 커밋이 단독으로는 깨질 수 있다.

알려진 한계로 두고 있었고 지금까지 고칠 계획이 없었다.

## 목표

훅이 실제로 커밋될 내용을 검증한다. stash 기반 검사가 후보이며, 비용(훅 실행 시간)과 안전성을 함께 본다.
