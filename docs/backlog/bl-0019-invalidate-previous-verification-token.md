# 확인 메일 재발송 시 이전 토큰을 무효화한다

- **ID:** BL-0019
- **기록일:** 2026-08-17

## 배경

확인 메일을 재발송해도 이전 토큰이 살아 있다 ([PD-0001-R8](../policy/pd-0001-signup-and-email-verification.md)). 재발송을 세 번 하면 계정 하나에 유효한 토큰이 세 개 동시에 존재한다.

토큰은 계정을 활성화할 수 있는 자격이므로, 유효한 개수가 늘어나면 유출 창구도 그만큼 늘어난다. 오래된 메일이 전달 과정 어딘가에 남아 있어도 여전히 사용 가능하다.

사용자의 기대와도 어긋난다. 메일을 다시 받은 사람은 이전 링크가 더 이상 동작하지 않는다고 생각한다.

이 규칙에는 현재 테스트가 없어서, 동작이 반대로 바뀌어도 `make verify`가 통과한다.

## 목표

한 계정에 유효한 확인 토큰이 항상 하나만 존재한다. 재발송이 이전 토큰을 즉시 사용 불가 상태로 만들고, 그 동작을 고정하는 테스트를 함께 둔다.

규칙이 바뀌므로 PD-0001을 수정하지 않고 새 정책 문서로 대체한다.
