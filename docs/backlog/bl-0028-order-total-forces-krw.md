# 주문 총액이 라인 통화를 무시하고 원화로 고정된다

- **ID:** BL-0028
- **기록일:** 2026-08-17

## 배경

주문 금액은 모두 원화여야 하고 비원화 상품이 포함된 견적과 주문을 거절한다 ([PD-0023-R5](../policy/pd-0023-order-lifecycle-price-and-cancellation.md)). 그러나 공용 `Money` 값 타입은 통화가 다른 금액의 연산을 막지 않으며, 주문 가격 계산도 단일 통화라면 비원화를 허용한다.

지금은 모든 판매 가격이 원화라 실제 청구에서 드러나지 않는다. 하지만 원화 제한이 값 타입의 불변식이 아니므로, 다른 금액 계산 경로가 생기면 통화가 다른 수치를 합칠 수 있다.

값 타입을 도메인별로 나누는 [BL-0009](bl-0009-split-money-per-domain.md)가 인접한 항목이다. 그쪽은 타입을 어디에 둘지의 문제이고, 이 항목은 서로 다른 통화를 더하는 연산 자체가 막혀 있지 않다는 문제다.

## 목표

통화가 다른 금액을 더하는 것이 불가능하다. 섞인 입력은 계산되지 않고 거절되며, 그 판정이 총액을 만드는 쪽이 아니라 금액 타입 자체에 있다.
