# 체크아웃 요청 자체가 멱등하지 않다

- **ID:** BL-0035
- **기록일:** 2026-08-22

## 배경

같은 장바구니로 체크아웃을 두 번 요청하면 주문이 두 개 만들어진다. 요청이 이전과 같은 것인지 확인하는 지점이 없다.

결제 쪽에 주문 식별자를 기준으로 한 멱등 장치를 두어도 이 경로는 막히지 않는다. 체크아웃마다 새 주문이 생기므로 주문 식별자가 매번 달라지고, 결제 입장에서는 서로 다른 주문의 정상적인 요청으로 보인다.

이 상태에 실제로 빠지는 경로가 있다. 체크아웃의 마지막 단계인 장바구니 비움이 실패하면 장바구니가 그대로 남는다. 사용자는 주문이 되지 않았다고 판단하고 다시 체크아웃하며, 그러면 같은 물건에 대한 두 번째 주문과 두 번째 결제가 만들어진다. 첫 주문은 정상적으로 성립해 있다.

[PD-0004](../policy/pd-0004-checkout-and-compensation.md)는 체크아웃 요청의 멱등성을 정하지 않는다고 명시해 두었다. 이 항목은 그 공백을 가리킨다.

## 목표

같은 체크아웃 요청이 여러 번 도착해도 주문과 결제가 한 벌만 만들어진다. 무엇을 같은 체크아웃 요청으로 볼 것인지, 그 판정이 얼마 동안 유효한지의 기준이 정해져 있다.
