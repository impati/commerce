# 동시 재고 예약이 멱등 결과를 보장하지 않는다

- **ID:** BL-0066
- **기록일:** 2026-09-13

## 배경

재고 예약은 주문 ID로 기존 예약을 확인한 뒤 재고 행을 잠그고, 같은 주문의 예약이 그사이에 생성됐는지 다시 조회한다. 같은 주문에 대한 요청이 겹치면 두 실행이 모두 예약이 없다고 판단할 수 있으며, 재조회가 최신 예약을 보지 못하거나 서로 다른 재고 행을 잠그면 두 실행이 예약 생성을 시도한다. 주문 ID의 유일성 제약이 중복 저장과 재고 변경은 막지만, 뒤늦은 요청은 기존 예약 결과 대신 데이터베이스 제약 예외를 받을 수 있다.

## 목표

같은 주문과 같은 품목으로 재고 예약이 동시에 호출돼도 재고에는 한 번만 반영되고 모든 호출자가 동일한 예약 결과를 얻는다. 같은 주문에 서로 다른 품목이나 수량을 요청하면 하나의 예약만 유지되고 나머지 요청은 명확한 충돌로 처리된다.
