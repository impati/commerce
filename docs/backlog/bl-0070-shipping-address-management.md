# 배송지를 관리하고 주문에 선택한다

- **ID:** BL-0070
- **기록일:** 2026-09-15

## 배경

현재 회원은 배송지를 추가하고 프로필에서 조회할 수 있지만, 기존 배송지를 수정·삭제하거나 기본 배송지를 바꿀 수 없다. 체크아웃 계약은 배송지 식별자를 받을 수 있지만 storefront는 배송지 선택 없이 기본 배송지를 사용한다.

주소가 바뀌거나 여러 배송지를 사용하는 회원은 주문에 사용할 주소를 완전하게 관리할 수 없다.

## 목표

회원이 자신의 배송지를 추가·수정·삭제하고 기본 배송지를 지정할 수 있다. 체크아웃에서 사용할 배송지를 직접 선택하며, 주문이 접수된 뒤에는 선택 당시의 배송지 사본이 보존된다.
