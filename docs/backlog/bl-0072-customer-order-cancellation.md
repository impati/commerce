# 고객이 출고 전 주문을 취소한다

- **ID:** BL-0072
- **기록일:** 2026-09-15

## 배경

주문 도메인에는 취소 상태가 있고 결제에는 승인 취소와 환불, 배송에는 준비 상태 취소가 있지만 이들을 고객의 주문 취소로 연결하는 흐름은 없다. 체크아웃 실패를 정리할 때만 각 되돌리기 기능이 사용된다.

결제가 끝난 주문을 고객이 취소할 방법이 없고, 일부 처리 뒤 중단되면 배송·결제·재고와 주문 상태를 함께 마무리할 주체도 없다.

## 목표

고객이 허용된 시점에 자신의 주문 전체를 취소할 수 있다. 취소된 주문은 배송되지 않고 결제 대금과 판매 가능 재고가 최종적으로 되돌아가며, 처리 중 중단이나 반복 요청이 있어도 하나의 취소 결과로 끝난다.
