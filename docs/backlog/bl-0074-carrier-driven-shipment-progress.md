# 배송 진행을 운영자와 배송사 사건으로 갱신한다

- **ID:** BL-0074
- **기록일:** 2026-09-15

## 배경

현재 storefront에서 인증된 사용자가 출고와 배송 완료를 직접 실행한다. 운송장 번호도 배송 생성 시 내부에서 발급하며 실제 배송사나 물류 작업과 연결되지 않는다.

실제 배송에서는 고객이 상태를 변경하지 않고 운영자의 출고 처리와 배송사의 진행 사건을 조회한다. 배송사 사건은 중복되거나 늦게 도착할 수 있고, 배송 실패·수취 거부·반송처럼 완료 이외의 결과도 생긴다.

## 목표

고객은 자신의 배송 진행과 운송장 정보를 조회하고, 배송 상태 변경은 권한 있는 운영 흐름이나 배송사 사건에서만 일어난다. 중복되거나 순서가 뒤바뀐 사건에도 상태가 후퇴하지 않으며 배송 실패와 반송이 정상적인 상태로 드러난다.
