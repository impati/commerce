# 배송 완료 주문의 반품과 환불을 처리한다

- **ID:** BL-0075
- **기록일:** 2026-09-15

## 배경

현재 배송이 시작된 뒤에는 배송을 취소할 수 없고 반품과 교환은 지원하지 않는다. 결제의 환불 기능은 체크아웃 결과를 확인하지 못한 실패를 정리할 때만 사용된다.

고객이 상품을 받은 뒤 구매를 되돌릴 업무가 없으므로 회수, 검수, 재고 판정, 환불과 고객 안내가 서로 연결되지 않는다.

## 목표

고객이 배송된 주문의 반품을 접수하고 회수·검수·환불 진행을 확인할 수 있다. 반품 결과에 따라 재고의 판매 가능 여부와 결제 환불이 일관되게 반영되며, 중단되거나 반복 처리되어도 하나의 종단 결과로 끝난다.
