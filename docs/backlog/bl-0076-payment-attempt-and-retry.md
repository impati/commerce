# 결제 시도와 결제 재시도를 표현한다

- **ID:** BL-0076
- **기록일:** 2026-09-15

## 배경

현재 한 주문에 결제 한 건만 존재하며, 결제 거절로 실패한 체크아웃은 같은 주문에서 다른 결제수단으로 이어갈 수 없다. 실패한 구매분은 장바구니에도 자동으로 돌아오지 않아 사용자가 구매를 다시 시작하기 어렵다.

실제 결제에서는 한 주문에 여러 시도가 생길 수 있지만 대금이 확정된 성공 결제는 하나여야 한다. 시도와 성공 결제를 구분하지 않으면 재시도를 막거나 이중 청구를 허용하게 된다.

## 목표

결제가 거절되거나 완료되지 않은 사용자가 구매 내용을 잃지 않고 다른 결제수단으로 다시 시도할 수 있다. 여러 시도의 이력이 남되 한 주문의 대금은 한 번만 확정된다.
