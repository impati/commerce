# 실제 결제 대행사와 결제 상태를 동기화한다

- **ID:** BL-0077
- **기록일:** 2026-09-15

## 배경

payment-service에는 결제 대행사 포트와 로컬 대역이 있지만 실제 결제 대행사 구현은 없다. 승인·매입·취소·환불 결과가 로컬 프로세스 안에서 즉시 만들어지므로 외부 응답 유실, 비동기 상태 변경과 대행사 웹훅을 실제 흐름으로 다루지 않는다.

실제 대행사를 연결하면 요청 응답과 최종 결제 상태가 다른 시점에 확정될 수 있고, 중복 웹훅과 상태 조회가 결제 결과를 판단하는 근거가 된다.

## 목표

실제 결제 대행사의 테스트 환경에서 승인·매입·취소·환불을 수행하고, 응답·상태 조회·웹훅을 통해 내부 결제 상태가 외부의 최종 사실과 일치한다. 외부 호출이 중복되거나 결과를 즉시 알 수 없어도 이중 청구나 잘못된 환불이 생기지 않는다.
