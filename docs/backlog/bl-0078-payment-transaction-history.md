# 결제 거래의 변경 불가능한 이력을 남긴다

- **ID:** BL-0078
- **기록일:** 2026-09-15

## 배경

현재 결제는 하나의 상태와 하나의 대행사 거래 식별자를 보관한다. 승인, 매입, 승인 취소와 환불이 일어나면 현재 상태만 바뀌므로 각 거래의 금액·시각·대행사 식별자와 처리 결과를 독립적으로 추적할 수 없다.

현재 상태만으로는 고객의 청구와 환불을 설명하기 어렵고, 대행사 거래 내역과 비교할 근거도 부족하다.

## 목표

승인·매입·취소·환불 각각의 거래가 금액, 발생 시각, 대행사 식별자와 결과를 가진 이력으로 보존된다. 현재 결제 상태와 별개로 과거 거래를 잃지 않으며 주문과 대행사 양쪽에서 같은 거래를 추적할 수 있다.
