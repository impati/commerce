# 커머스 운영 업무를 백오피스에서 처리한다

- **ID:** BL-0081
- **기록일:** 2026-09-15

## 배경

현재 상품과 재고의 쓰기 기능, 배송 상태 전이와 각종 내부 조회는 시드나 내부 API에 흩어져 있다. 주문 검색, 출고 대기, 반품 검수, 환불 처리와 자동 복구 실패 확인을 한곳에서 수행할 운영자 기능과 권한 모델이 없다.

운영 중 문제가 생기면 내부 API를 직접 호출하거나 데이터베이스를 조회해야 하며, 누가 어떤 업무를 처리했는지도 일관되게 남지 않는다.

## 목표

권한 있는 운영자가 상품·재고·주문·배송·반품·환불과 자동 복구 실패를 업무 목록에서 찾고 처리할 수 있다. 고객 권한과 운영 권한이 분리되고, 주요 운영 조작의 수행자와 시각이 추적된다.
