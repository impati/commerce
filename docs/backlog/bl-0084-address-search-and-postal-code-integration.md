# 주소 검색과 우편번호 조회를 외부 시스템과 연동한다

- **ID:** BL-0084
- **기록일:** 2026-09-18

## 배경

배송지 관리와 주문 선택을 완성하는 BL-0070에서는 기존 배송지 항목을 직접 입력하고 화면과 서버에서 검증하는 범위로 진행하기로 했다. 배송지 입력에는 주소 검색과 우편번호 조회를 제공하는 외부 시스템 연동도 필요하지만, 이번 작업에서는 포함하지 않는다.

외부 시스템의 선택과 구체적인 연동 방식은 이 항목을 시작할 때 별도 인터뷰에서 논의한다.

## 목표

고객이 외부 시스템을 통한 주소 검색과 우편번호 조회를 활용해 배송지를 입력할 수 있다.
