# 체크아웃 접수 전 멱등성 경합을 확인한다

- **ID:** BL-0085
- **기록일:** 2026-09-19

## 배경

체크아웃은 멱등 키에 연결된 주문이 이미 접수됐으면 기존 결과를 반환한다. 그러나 주문을 접수하기 전에 장바구니·견적·회원 배송지를 조회하고 검증하는 동안에는 멱등 키가 아직 기록되지 않는다. 같은 키의 요청이 이 구간에서 겹치면 서로 다른 시점의 상태를 읽어 한 요청은 주문을 접수하고 다른 요청은 거절할 수 있다.

여러 요청의 실행과 상태 변경이 짧은 시간에 겹쳐야 하므로 실제 발생 빈도는 운영에서 확인하기로 했다.

## 목표

운영에서 체크아웃 접수 전 멱등성 경합의 발생 여부와 빈도를 확인하고, 대응이 필요하면 같은 멱등 키로 겹친 요청이 하나의 접수 결과를 일관되게 확인할 수 있도록 한다.
