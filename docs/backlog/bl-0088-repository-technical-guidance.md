# 레포 기술 지침과 외부 어댑터 책임 경계를 명시한다

- **ID:** BL-0088
- **기록일:** 2026-09-24

## 배경

BL-0074 구현 인터뷰에서는 실제 외부 업체를 연결하지 않는다는 범위를 정했지만, 택배사 프로토콜 전체를 대역에 맡길지 인증·통신만 어댑터에 맡기고 멱등성·결과 불명 복구·로컬 상태 수렴은 애플리케이션이 소유할지 명시하지 않았다. 그 결과 레포가 요구하는 운영 완성도와 테스트 의무를 구현 전에 일관되게 적용하지 못했다. 에이전트가 공통으로 읽는 루트 `AGENTS.md`도 없어 이 레포의 아키텍처 성격과 기술 기준을 하네스가 발견할 표준 진입점이 없다.

## 목표

루트 `AGENTS.md`를 표준 진입점으로 두고 이 레포의 시스템 경계, 외부 어댑터와 애플리케이션의 책임, 결과 불명·재시도·멱등성·동시성·데이터 수렴 원칙, 위험에 대응하는 테스트 의무를 간결하게 명시한다. 하네스는 이 문서를 읽어 레포별 기준을 인터뷰와 구현·리뷰에 적용할 수 있고, 구체적인 제품·기술 판단은 이 레포 안에서 유지되게 한다.
