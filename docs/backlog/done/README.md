# 완료한 백로그

완료 기준 검증을 통과한 항목이 여기로 온다. 항목 파일은 그대로 두고 위치만 바꾼다 — 상태를 위치로만 구분하기 위해서다.

- 옮기는 시점은 완료 1회뿐이다. 검증에 실패했거나 작업을 중단했으면 옮기지 않는다.
- `git mv`로 옮기고 그 변경을 작업의 마지막 커밋에 포함한다.
- **여기 있는 항목도 `BL-NNNN` 채번 대상이다.** 다음 번호는 열린 항목과 이 디렉터리를 함께 세서 정하고, 번호를 재사용하지 않는다.
- 무엇을 왜 했는지는 `git log`가 정본이다. 여기에 완료 요약을 덧붙이지 않는다.
