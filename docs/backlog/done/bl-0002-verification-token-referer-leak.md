# 인증 링크 토큰의 Referer 유출

- **ID:** BL-0002
- **기록일:** 2026-08-16

## 배경

인증 링크가 `/verify?token=...` 형태로 토큰을 URL에 담는다. 그 페이지가 외부 호스트에 요청을 보내면 `Referer` 헤더에 토큰이 실려 나간다.

프론트가 `images.unsplash.com`에서 상품 이미지를 로드하므로 이 경로가 실재한다. 인증 처리 후 `history.replaceState`로 URL을 지우지만 이미지 로드가 그보다 먼저 시작되므로 순서상 막지 못한다.

세션 토큰은 헤더로만 보내므로 이 문제가 없다. URL에 토큰이 실리는 곳은 인증 링크 하나다.

## 목표

인증 토큰이 외부 호스트로 새어 나가지 않는다.

대응 후보는 둘이다.

| 방법 | 효과 |
| --- | --- |
| `Referrer-Policy: no-referrer` | 브라우저가 Referer를 보내지 않는다. 한 줄이고 즉시 효과가 있다 |
| 토큰을 URL 프래그먼트(`#token=`)로 옮긴다 | 프래그먼트는 서버로 전송되지 않고 Referer에도 실리지 않는다. 더 근본적이지만 링크 형태와 프론트 파싱이 바뀐다 |

먼저 헤더로 막고, 프래그먼트 전환은 별도로 판단한다.
