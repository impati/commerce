# 재고 예약의 동시 종단 명령이 멱등하지 않다

- **ID:** BL-0065
- **기록일:** 2026-09-12

## 배경

재고 예약의 확정과 해제는 이미 종단 상태라면 같은 결과를 돌려주지만, 예약 상태를 잠그지 않고 읽은 뒤 재고 행만 잠근다.
같은 예약에 대한 요청이 겹치면 두 실행이 모두 `RESERVED` 상태를 읽을 수 있고, 먼저 끝난 실행 뒤의 실행은 갱신된 재고와 과거 예약 상태를 함께 사용해 충돌한다.
체크아웃처럼 호출자가 안전하게 같은 명령을 반복하는 흐름에서도 동시 호출은 종단 결과 대신 예외를 받을 수 있다.

이 문제는 체크아웃에 한정되지 않고 재고 예약 자체의 동시 상태 전이 규칙에 속한다. 순서대로 같은 명령을 반복하는 현재 테스트로는 드러나지 않는다.

## 목표

같은 예약의 확정 또는 해제가 동시에 호출돼도 재고에는 한 번만 반영되고, 같은 명령의 모든 호출자는 동일한 종단 결과를 얻는다. 확정과 해제가 경합하면 먼저 확정된 상태를 유지하고 반대 명령은 명확한 충돌로 처리한다. 실제 동시 실행 검증으로 이 규칙을 고정한다.
