# 회원 주문 내역과 진행 이력을 제공한다

- **ID:** BL-0068
- **기록일:** 2026-09-15

## 배경

현재 회원은 주문 식별자를 알고 있을 때만 주문 한 건을 조회할 수 있다. 체크아웃 직후에는 브라우저에 남은 주문 식별자로 결과를 이어서 볼 수 있지만, 시간이 지나거나 다른 기기에서 접속하면 과거 주문을 다시 찾을 경로가 없다.

주문 응답도 주문·결제·배송의 현재 상태만 보여준다. 사용자는 주문이 언제 접수되고 결제되었으며 어디까지 배송되었는지, 취소나 환불이 진행 중인지 시간 순서로 확인할 수 없다.

## 목표

회원이 자신의 주문 목록에서 과거 주문을 찾고, 주문 상세에서 주문·결제·배송·취소·환불의 진행 이력을 시간 순서로 확인할 수 있다. 다른 회원의 주문은 목록과 상세 어느 경로에서도 드러나지 않는다.
