# 장바구니 상품의 수량을 바꾸고 삭제한다

- **ID:** BL-0069
- **기록일:** 2026-09-15

## 배경

현재 장바구니는 상품을 추가하거나 전체를 비울 수만 있다. 같은 상품을 다시 담으면 수량이 늘어나지만, 사용자가 원하는 수량으로 변경하거나 특정 상품만 삭제할 수 없다.

여러 상품을 비교하며 구매 수량을 조정하는 장바구니의 기본 역할이 추가 동작에만 한정되어 있다.

## 목표

회원이 장바구니의 각 상품 수량을 명시적으로 변경하고 원하는 상품만 삭제할 수 있다. 변경된 장바구니의 금액과 구매 대상이 체크아웃 직전까지 일관되게 보인다.
