# 주문 금액의 구성과 배송비를 확정한다

- **ID:** BL-0071
- **기록일:** 2026-09-15

## 배경

현재 주문 총액은 상품 라인 금액의 합뿐이다. 배송비와 그 부과 기준이 없고, 고객이 결제 전에 상품 금액과 최종 청구 금액의 구성을 확인할 수 있는 표현도 없다.

향후 할인이나 환불이 도입되면 하나의 총액만으로는 어떤 금액이 청구되고 되돌아갔는지 설명하기 어렵다. 쿠폰을 지금 도입하지 않더라도 주문 금액의 기본 구성은 먼저 분명해야 한다.

## 목표

결제 전에 상품 금액, 배송비와 최종 결제 금액이 구분되어 보이고 주문 시점의 값으로 확정된다. 주문 이후 가격이나 배송비 기준이 바뀌어도 이미 성립한 주문의 금액 구성은 변하지 않는다.
