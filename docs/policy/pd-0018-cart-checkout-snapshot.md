# PD-0018: 장바구니와 구매 스냅샷

- **날짜:** 2026-09-11

## 배경과 문제

장바구니는 아직 확정되지 않은 구매 의도다. 체크아웃이 시작된 뒤에도 같은 장바구니를 수정할 수 있으므로, 구매 대상과 나중에 새로 담은 항목을 구분하지 않고 비우면 새 의도까지 삭제된다.

## 목표

장바구니는 가격이나 재고를 약속하지 않으며, 체크아웃이 접수한 구매분은 이후 장바구니 변경과 분리된다.

## 정책

- **PD-0018-R1:** 같은 상품을 다시 담으면 기존 줄의 수량을 합산한다.
- **PD-0018-R2:** 담는 수량은 1 이상이며 상한은 두지 않는다.
- **PD-0018-R3:** 등록되지 않은 상품은 담을 수 없다.
- **PD-0018-R4:** 담는 시점에는 재고와 가격을 확정하지 않는다.
- **PD-0018-R5:** 장바구니 조회는 저장 상태를 바꾸지 않는다. 장바구니가 없으면 저장하지 않은 빈 장바구니를 반환한다.
- **PD-0018-R6:** 체크아웃은 서버가 발급한 주문 식별자와 예상 장바구니 버전으로 구매분을 한 번만 분리한다. 버전이 다르면 분리하지 않고 실패하며, 같은 주문 식별자의 반복 요청은 최초에 분리한 같은 사본을 반환한다.
- **PD-0018-R7:** 분리한 구매분은 체크아웃 실패 시 자동으로 복원하지 않는다. 사용자가 나중에 새로 담은 항목은 해당 주문의 완료나 복구가 삭제하지 않는다.
- **PD-0018-R8:** 사용자는 현재 장바구니를 명시적으로 비울 수 있다. 비운 장바구니는 없는 장바구니와 구분된다.

## 정책이 정하지 않는 것

- 실패한 구매분을 다시 담는 사용자 기능.
- 비회원 장바구니와 장바구니 보관 기간.
- 줄 단위 삭제와 수량 수정.

## 재검토 조건

- 실패한 구매를 한 동작으로 다시 담아야 할 때.
- 하나의 장바구니에서 일부 항목만 결제할 때.
- 비회원 구매를 허용할 때.
