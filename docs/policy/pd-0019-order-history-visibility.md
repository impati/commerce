# PD-0019: 주문 내역 노출과 진행 이력

- **날짜:** 2026-09-15
- **대체:** 해당 없음
- **대체됨:** 해당 없음

## 배경과 문제

체크아웃은 주문을 먼저 접수한 뒤 재고, 결제와 배송을 차례로 처리하며 중단된 단계는 별도 실행자가 이어간다. 따라서 접수된 기록에는 정상 처리 중인 건, 실패를 되돌리는 중인 건, 자동 복구가 끝난 건과 운영 확인이 필요한 건이 함께 존재한다.

이들을 모두 회원의 주문 내역에 노출하면 내부 복구 과정이 구매 결과처럼 보인다. 반대로 배송까지 끝난 주문만 노출하면 결제가 확정되어 배송을 기다리는 정상 주문을 찾을 수 없다. 어떤 기록을 고객의 주문으로 보여줄지와 주문 진행 이력의 소유권 경계가 필요하다.

## 목표

회원의 주문 내역에는 체크아웃 업무의 결과가 확정된 주문만 나타나고, 확정된 뒤의 배송 진행은 같은 주문에서 계속 확인할 수 있다. 주문 식별자를 아는 것만으로 다른 회원의 주문이나 진행 이력을 알아낼 수 없다.

## 정책

- **PD-0019-R1:** 회원의 주문 내역에는 체크아웃이 성공 또는 실패로 종결된 주문만 나타난다. 근거: 처리 중인 단계는 자동 복구가 책임지는 내부 과정이며 아직 고객에게 제시할 구매 결과가 아니다.
- **PD-0019-R2:** 성공으로 종결된 체크아웃은 배송 진행 여부와 관계없이 주문 내역에 나타난다. 근거: 결제가 확정된 주문은 배송 완료 전에도 회원이 찾아볼 수 있어야 한다.
- **PD-0019-R3:** 실패로 종결된 체크아웃도 주문 내역에 나타난다. 실패를 되돌리는 절차가 진행 중인 동안에는 나타나지 않고, 그 절차가 끝나 하나의 실패 결과로 확정된 뒤에만 나타난다. 근거: 실패한 구매 사실은 회원이 다시 확인할 수 있어야 하지만 정리되지 않은 중간 상태를 확정 결과처럼 보여서는 안 된다.
- **PD-0019-R4:** 자동 복구가 계속되는 주문과 운영 확인이 필요한 주문은 회원의 주문 내역에 나타나지 않는다. 근거: 두 상태 모두 성공이나 실패로 확정되지 않았고 후속 처리의 주체가 고객이 아니다.
- **PD-0019-R5:** 체크아웃 요청 직후의 결과 조회는 주문 내역과 별개이며 처리 중 상태를 응답할 수 있다. 근거: 요청한 고객은 접수 결과와 주문 식별자를 받아 자동 복구가 끝날 때까지 확인할 수 있어야 한다.
- **PD-0019-R6:** 주문 상세에는 회원에게 의미 있는 주문 진행 사실과 각 사실이 발생한 시각이 시간 순서로 나타난다. 내부 실행 단계, 재시도 횟수, 발행 상태와 내부 오류 내용은 나타나지 않는다. 근거: 고객은 구매 진행을 이해할 정보가 필요하지만 내부 복구와 운영 정보는 고객의 판단 대상이 아니다.
- **PD-0019-R7:** 회원은 자신이 소유한 주문의 목록, 상세와 진행 이력만 조회할 수 있다. 다른 회원이 소유한 주문은 존재하지 않는 주문과 같은 결과로 거절한다. 근거: 주문 식별자를 아는 것만으로 주문의 존재나 상품, 금액, 배송지와 결제 상태를 알아낼 수 없어야 한다.

## 거절하는 시나리오

- 정상 처리나 실패 보상이 진행 중인 주문은 회원의 주문 내역에 나타나지 않는다 (R1, R3, R4).
- 운영 확인이 필요한 주문은 회원의 주문 내역에 나타나지 않는다 (R4).
- 다른 회원의 주문 식별자로 상세나 진행 이력을 조회하면 존재하지 않는 주문과 같은 결과를 받는다 (R7).

## 허용하는 시나리오

- 체크아웃 요청 직후에는 주문 내역에 아직 나타나지 않는 주문의 처리 중 결과를 해당 요청의 결과 조회에서 확인할 수 있다 (R5).
- 체크아웃이 성공으로 끝났다면 배송 준비 또는 배송 중인 주문도 주문 내역에 나타난다 (R2).
- 실패를 되돌리는 절차까지 끝난 주문은 실패한 구매로 주문 내역에 남는다 (R3).
- 배송이 진행되거나 완료되면서 새로 일어난 고객 관련 사실은 이미 노출된 주문의 진행 이력에 이어진다 (R2, R6).

## 정책이 정하지 않는 것

- 주문 목록의 페이지 크기, 커서 형식과 화면 배치.
- 고객에게 표시할 상태 이름과 문구.
- 진행 사실과 발생 시각을 저장하고 조회하는 구현 방식.
- 운영 확인 대상의 알림, 재처리와 관리 방법.
- 주문과 진행 이력의 보관 기간.

## 고려한 대안

**접수된 모든 주문을 내역에 표시한다 — 채택하지 않음.** 정상 복구 중인 단계와 실패를 되돌리는 중간 단계까지 고객의 구매 결과처럼 보인다. 중간 과정의 후속 처리 주체는 고객이 아니라 자동 복구 또는 운영 절차다.

**성공한 주문만 표시한다 — 채택하지 않음.** 실패로 확정된 구매를 회원이 다시 확인할 수 없고, 이후 같은 상품을 다시 구매하거나 문의할 때 근거가 사라진다.

**배송 완료와 취소처럼 주문 생애주기의 끝 상태만 표시한다 — 채택하지 않음.** 결제가 확정되어 배송을 기다리는 정상 주문이 내역에서 사라진다. 이 정책이 판정하는 종결은 배송의 끝이 아니라 체크아웃 업무 결과의 확정이다.

## 재검토 조건

- 처리 중인 체크아웃에서 고객의 선택이나 추가 행동이 필요해질 때.
- 자동 복구 시간이 길어져 고객이 주문 내역에서도 진행 중 상태를 확인해야 할 필요가 반복될 때.
- 운영 확인 대상 주문을 고객에게 별도 상태로 안내하기로 할 때.
- 비회원 주문 조회나 주문 데이터 보관 기간을 도입할 때.
