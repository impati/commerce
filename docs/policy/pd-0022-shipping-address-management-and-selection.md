# PD-0022: 배송지 관리와 주문 선택

- **날짜:** 2026-09-18

## 배경과 문제

고객은 주소가 바뀌거나 여러 주소를 사용할 때 자신의 배송지를 관리하고 주문에 사용할 주소를 선택할 수 있어야 한다. 오래된 화면의 변경이 최신 주소록을 덮어쓰거나, 고객이 확인하지 않은 주소로 주문되는 상황을 막는다.

## 목표

고객이 확인한 배송 정보로 주문하며, 주소록의 기본 배송지와 동시 변경이 일관되게 유지된다.

## 정책

- **PD-0022-R1:** 인증된 회원은 자신의 배송지만 추가·조회·수정·삭제·기본 지정하고 주문에 선택할 수 있다.
- **PD-0022-R2:** 주소록이 비어 있지 않으면 기본 배송지는 정확히 하나다. 첫 배송지는 자동으로 기본 지정하고, 다른 배송지를 기본 지정하면 기존 지정은 해제한다.
- **PD-0022-R3:** 기본 배송지를 삭제하면 남은 배송지 중 가장 먼저 등록한 것을 기본 지정한다. 마지막 배송지도 삭제할 수 있으나 배송지가 없는 동안 새 주문을 접수하지 않는다.
- **PD-0022-R4:** 고객이 조회한 주소록보다 최신 변경이 있으면 그 화면의 관리 요청을 거절한다. 최신 주소록을 보여주고 다시 조작하도록 하며 오래된 변경을 자동 재적용하지 않는다. 추가 요청의 중복도 주소를 중복 생성하지 않는다.
- **PD-0022-R5:** 주문 화면 진입 시 기본 배송지를 선택한다. 고객이 다른 배송지를 선택할 수 있고, 기본 지정 변경은 이미 선택한 배송지를 바꾸지 않는다.
- **PD-0022-R6:** 선택한 배송지의 수령인·전화번호·주소·도시·우편번호가 고객이 확인한 값과 다르거나 해당 배송지가 삭제됐으면 새 주문을 접수하지 않고 재확인·재선택을 요구한다. 별칭·기본 지정이나 다른 배송지의 변경만으로 재확인을 요구하지 않는다.
- **PD-0022-R7:** 이미 접수된 주문은 주소록의 이후 변경·삭제와 관계없이 접수 당시 배송지 사본을 유지한다. 같은 주문 요청의 재시도도 기존 사본을 사용한다 (PD-0017-R1, R3).
- **PD-0022-R8:** 배송지의 별칭·수령인·전화번호·주소·도시·우편번호는 필수다. 공백만 있는 값과 저장 가능한 길이를 초과한 값은 거절한다.
- **PD-0022-R9:** 저장 결과를 알 수 없으면 관리 요청을 자동 반복하지 않고 조회로 최신 상태를 확인한다. 확인 전에는 추가 조작과 새 주문을 제한한다. 조회도 실패하면 조회를 다시 시도할 수 있고, 입력은 확인이 끝날 때까지 보존한다.
- **PD-0022-R10:** 관리 화면에서 주소록의 최신 변경을 확인하면 작성 중인 입력을 버리고 서버의 최신 배송지 값으로 초기화한다. 편집하던 배송지가 삭제됐으면 편집을 종료하며, 다른 배송지의 변경도 예외로 두지 않는다.

## 거절하는 시나리오

- 남의 배송지를 수정·삭제·기본 지정하거나 주문에 선택하는 요청 (R1).
- 다른 탭에서 주소록을 바꾼 뒤 오래된 화면에서 보내는 관리 요청 (R4).
- 화면에서 확인한 배송 정보와 현재 배송 정보가 다르거나 삭제된 주소로 보내는 새 주문 요청 (R6).

## 허용하는 시나리오

- 마지막 배송지를 삭제하고 나중에 새 배송지를 등록한다 (R3).
- 선택한 배송지의 별칭이나 기본 지정만 바뀌어도 확인한 배송 정보가 같으면 주문한다 (R6).
- 주문 접수 후 배송지를 수정·삭제하고 기존 주문 결과를 다시 확인한다 (R7).
- 다른 화면의 변경이나 같은 화면의 다른 관리 조작으로 주소록이 갱신되면 작성 중인 입력을 초기화한다 (R10).

## 정책이 정하지 않는 것

- API 경로와 화면 컴포넌트 구성.
- 주소록 버전 및 배송 정보 확인값의 표현과 저장 방식.
- 외부 주소 검색·우편번호 조회 시스템과 연동 방식.

## 고려한 대안

- 기본 배송지 삭제 시 대체 주소 선택을 강제하는 대신 등록 순서로 자동 지정해 삭제를 완료할 수 있게 한다.
- 마지막 관리 요청을 그대로 적용하는 대신 오래된 변경을 거절해 다른 변경의 유실을 막는다.
- 최신 주소로 곧바로 주문하거나 별칭 변경에도 재확인을 요구하는 대신 실제 배송 정보가 달라졌을 때 재확인한다.

## 재검토 조건

배송지 구조나 기본 지정 규칙, 주문 배송지 변경 기능을 확장할 때 관련 규칙을 다시 검토한다.
