# PD-0027: 배송 후 반품과 환불

- **날짜:** 2026-09-25
- **대체:** 해당 없음
- **대체됨:** 해당 없음

## 배경과 문제

배송이 끝난 주문을 고객이 되돌리거나 배송 실패 상품이 판매자에게 반송되어도 회수, 검수, 재고
판정과 환불을 잇는 규칙이 없다. 고객 요청과 택배사 반송은 시작점이 다르지만, 어느 경우에도 상품과
대금의 최종 상태가 설명 가능해야 한다. 특히 반품 가능 기간, 배송비 부담, 환불 시점과 판매 불가
상품의 처리를 정하지 않으면 같은 주문이 요청 사유나 처리 순서에 따라 다른 결과를 가질 수 있다.

## 목표

배송 후 주문 전체를 되돌리는 반품이 고객 요청과 배송 실패 반송 모두에서 일관되게 처리되게 한다.
회수, 환불, 검수와 재고 처리가 중단되거나 반복되어도 고객에게 진행 상태가 보이고 하나의 종단
결과로 수렴하게 한다.

## 정책

- **PD-0027-R1:** 반품은 한 주문의 모든 상품과 수량을 한 번에 되돌리며 부분 반품과 교환은
  지원하지 않는다. 근거: 주문당 결제와 배송이 하나인 현재 직매입 범위에서 먼저 배송 후 고객
  여정을 완결하고, 금액·배송비 배분이 필요한 부분 반품은 별도로 정하기 위해서다.
- **PD-0027-R2:** 배송 완료 주문은 고객 요청으로 반품을 시작하고, 최종 배송 실패 뒤 상품이
  판매자에게 반송 완료된 주문은 고객 요청 없이 같은 반품 후속 절차를 시작한다. 근거: 고객이 받은
  상품의 회수와 이미 돌아온 상품은 물류 시작점만 다르고 검수·재고·환불의 종결 책임은 같기 때문이다.
- **PD-0027-R3:** 고객 반품 사유는 `단순 변심`, `상품 파손·하자`, `오배송·계약 내용 불일치`로
  구분하며 설명을 보조 정보로 받는다. 파손·하자 또는 계약 불일치의 연장 기간을 적용하려면 고객이
  문제를 안 날을 함께 제시한다. 근거: 접수 기간과 회수비 부담을 일관되게 판정하면서도 고객의 구체적
  설명을 잃지 않기 위해서다.
- **PD-0027-R4:** 단순 변심은 배송 완료일의 다음 날부터 7일째가 끝날 때까지 접수할 수 있다.
  상품 파손·하자와 오배송·계약 내용 불일치는 배송 완료일부터 3개월 이내이면서 고객이 문제를 안 날
  또는 알 수 있었던 날부터 30일 이내여야 한다. 근거: 국내 전자상거래의 청약철회 기간보다 고객의
  권리를 좁히지 않기 위해서다.
- **PD-0027-R5:** 반품 자격을 충족한 고객 요청은 별도 운영자 승인 없이 접수하고 택배 회수를
  요청한다. 원 배송지를 기본 회수지로 사용하되 택배사 집하 전에는 고객이 회수지를 수정할 수 있다.
  근거: 운영 백오피스가 없어도 고객이 반품 여정을 끝낼 수 있어야 하고 실제 회수 위치는 원 배송지와
  다를 수 있기 때문이다.
- **PD-0027-R6:** 고객은 택배사 집하 전까지만 반품 요청을 철회할 수 있다. 최종 회수 실패가
  확인되면 최초 접수가 기간 안에 있었던 같은 반품 건은 기간이 지난 뒤에도 회수지를 수정해 재예약할
  수 있다. 고객이 스스로 철회한 뒤 다시 접수하려면 새 접수 시점에도 반품 기간 안이어야 한다. 근거:
  택배사 실패로 적법한 요청이 사라지지 않게 하되 고객이 끝낸 요청을 무기한 다시 열어 두지 않기
  위해서다.
- **PD-0027-R7:** 고객 반품은 택배사가 상품을 집하한 사실이 확정되면 환불을 시작한다. 배송 실패
  반송은 판매자가 상품을 인수한 사실이 확정되면 환불을 시작한다. 근거: 고객이 상품의 점유를 넘긴
  뒤에는 검수 완료를 기다리게 하지 않으면서, 실제 회수 전 환불로 상품과 대금을 모두 잃는 상태를
  피하기 위해서다.
- **PD-0027-R8:** 단순 변심 주문이 최초 배송비 3,000원을 지불했다면 원 결제액에서 반품 회수비
  3,000원을 차감해 환불한다. 최초 배송이 무료였다면 반품 회수비도 고객에게 부담시키지 않는다.
  상품 파손·하자, 오배송·계약 내용 불일치와 배송 실패 반송은 원 결제액 전액을 환불한다. 근거:
  고객 사유의 회수 비용은 고객이 부담하되 무료배송 약속을 반품에서 뒤집지 않고, 판매자 책임이나
  배송 실패 비용은 고객에게 넘기지 않기 위해서다.
- **PD-0027-R9:** 환불액은 집하 시점에 접수된 사유로 확정하며 후속 검수 결과로 줄이거나 다시
  청구하지 않는다. 고객 책임의 사용·훼손이 확인되어도 확정한 환불을 유지한다. 근거: 상품을 다시
  고객에게 보내지 않는 범위에서 판매자가 상품과 대금을 모두 보유하는 결과를 만들지 않기 위해서다.
- **PD-0027-R10:** 검수 결과가 정상·재판매 가능이면 주문의 모든 상품 수량을 판매 가능 재고로
  복원한다. 파손·사용·훼손 또는 그 밖의 판매 불가 결과이면 정상 판매 가능 재고에 포함하지 않고
  반품, 상품, 수량, 검수 결과와 회원의 연결 이력을 남긴다. 근거: 판매할 수 없는 상품이 가용 수량을
  부풀리지 않으면서 반환된 실물과 판정 근거를 잃지 않기 위해서다.
- **PD-0027-R11:** 판매자가 상품을 인수한 뒤 72시간 안에 검수 결과가 확정되지 않으면 해당 상품은
  `미검수·판매 불가`로 격리하고 반품 절차를 계속 종결한다. 근거: 검수 누락이 반품을 무기한 열어
  두거나 확인하지 않은 상품을 판매 가능 재고로 만드는 일을 막기 위해서다.
- **PD-0027-R12:** 환불 결과, 판매자 상품 인수와 검수·재고 처리가 모두 확정된 뒤 주문은
  `반품 완료`가 된다. 접수부터 종결 전까지는 기존 주문 상태와 별도의 반품 진행 상태를 보여주며,
  출고 전 `주문 취소`와 배송 후 `반품 완료`를 구분한다. 근거: 돈이나 실물 처리가 남았는데 완료로
  보이지 않게 하고 이미 일어난 배송 사실을 지우지 않기 위해서다.
- **PD-0027-R13:** 고객에게 반품 접수, 택배 집하와 환불 시작, 최종 반품 완료를 알리고 자동으로
  결과를 판정할 수 없어 운영 확인이 필요할 때도 그 상태를 알린다. 운송과 검수의 세부 진행은 주문
  상세 이력에서 확인한다. 근거: 의미 있는 종결점은 놓치지 않되 중간 사건마다 알림을 보내지 않기
  위해서다.
- **PD-0027-R14:** 같은 반품 요청, 택배 사건, 환불과 재고 처리가 반복되거나 순서가 바뀌어도 각
  효과는 한 번만 적용되고 먼저 확정된 물리적 사실을 후퇴시키지 않는다. 결과를 알 수 없거나 실행이
  중단되면 성공·실패를 추측하지 않고 저장된 진행 상태와 같은 업무 식별자로 확인·재시도하며, 자동
  판정이 안전하지 않으면 고객에게 확인 중으로 표시한다. 근거: 재시도와 외부 응답 유실이 이중 환불,
  재고 중복 복원이나 서로 다른 종단 결과를 만들지 않아야 하기 때문이다.
- **PD-0027-R15:** 고객 책임 검수 이력은 이번 정책만으로 고객의 구매나 이후 반품을 자동 제한하지
  않는다. 근거: 제한 조건, 기간, 고객 고지, 이의 제기와 오판 정정 기준을 별도로 합의하지 않은 채
  정상 고객에게 불이익을 주지 않기 위해서다.

## 거절하는 시나리오

- 배송 완료 전 고객이 반품을 요청하는 경우. 집하 전은 주문 취소, 집하 뒤 배송 중은 현재 물류
  결과가 먼저 확정되어야 한다 (R2).
- 한 주문의 일부 상품이나 수량만 반품하거나 교환하려는 요청 (R1).
- 단순 변심 기간 또는 파손·하자·오배송의 두 기간 조건 중 하나라도 지난 요청 (R4).
- 택배사 집하 뒤 회수지를 바꾸거나 반품 요청을 철회하는 요청 (R5, R6).
- 이미 확정된 같은 반품에 다른 환불 금액이나 재고 효과를 중복 적용하려는 요청 (R14).

## 허용하는 시나리오

- 최초 배송이 무료였던 단순 변심 반품에서 원 결제액 전액을 환불한다 (R8).
- 최초 배송비 3,000원을 지불한 단순 변심 반품에서 회수비 3,000원을 차감한다 (R8).
- 하자를 신고한 상품이 후속 검수에서 고객 책임 훼손으로 판정되어도 집하 때 확정한 환불액은 줄지
  않고, 상품만 판매 불가로 격리된다 (R9, R10).
- 회수 실패가 반품 기간 뒤에 확정되어도 기간 안에 접수한 같은 반품의 회수를 다시 예약한다 (R6).
- 최종 배송 실패 상품이 판매자에게 반송 완료되면 별도 고객 요청이나 역배송 없이 전액 환불과
  검수로 이어진다 (R2, R7, R8).
- 검수 담당 처리가 누락되어도 72시간 뒤 상품은 판매 가능 재고에 섞이지 않고 반품은 종결된다
  (R11, R12).

## 정책이 정하지 않는 것

- 부분 반품, 부분 수량 환불, 교환과 여러 번의 반품.
- 실제 택배사·결제 대행사 선택과 업체별 인증·통신 규격.
- 운영 백오피스, 운영자 인증·권한과 검수 화면의 구체적인 형태.
- API 필드, 저장 구조, 재시도 간격, 화면 배치와 알림 문구.
- 판매 불가 상품의 할인 재판매, 폐기, 수리 또는 다른 등급 재분류.
- 고객 책임 이력을 이용한 구매·반품 제한 조건과 이력 보관 기간.
- 주문제작품, 신선식품, 디지털 상품 등 상품 유형별 별도 반품 제한.

## 고려한 대안

- 부분 반품을 함께 지원하는 방안은 부분 환불, 여러 반품의 경합과 배송비 배분 규칙을 한 번에
  요구하므로 채택하지 않았다.
- 고객이 배송받은 주문만 처리하는 방안은 이미 판매자에게 돌아온 배송 실패 상품의 대금과 재고가
  끝나지 않으므로 채택하지 않았다.
- 검수 뒤 환불하는 방안은 최종 사유로 비용을 정할 수 있지만 상품을 넘긴 고객의 환불이 검수
  지연에 묶이므로 채택하지 않았다.
- 모든 단순 변심에 왕복 배송비를 차감하는 방안은 무료배송 주문에도 반품 때 비용을 부과하므로
  채택하지 않았다.
- 고객 책임 훼손에서 환불을 거절하고 상품도 돌려주지 않는 방안은 판매자가 상품과 대금을 모두
  보유하므로 채택하지 않았다.
- 고객 책임 이력으로 즉시 구매나 반품을 제한하는 방안은 공정한 제한과 이의 제기 정책이 없어
  별도 결정으로 미뤘다.

## 재검토 조건

- 부분 반품, 부분 수량 환불 또는 교환을 지원할 때.
- 무료배송과 반품 회수비 정책 또는 3,000원 배송비 기준이 바뀔 때.
- 상품 유형별 반품 제한이나 반품 증빙을 도입할 때.
- 고객 책임 이력에 따라 구매·반품을 제한할 때.
- 판매 불가 상품을 수리하거나 별도 등급과 가격으로 다시 판매할 때.
- 여러 판매자, 여러 출고지나 여러 배송이 한 주문을 이행할 때.
